# 基礎地球惑星物質学 / Introduction to the Earth and Planetary Materials Science

金沢大学 学部2年生向け専門科目「基礎地球惑星物質学」の教材アプリと配布資料を公開するリポジトリです。

## 教材アプリ

ブラウザ（スマートフォン可）で動くインタラクティブな教材です。

- 一覧ページ：https://yoichiusui-kanazawa.github.io/Introduction-to-the-Earth-and-Planetary-Materials-Science/

## 構成

| フォルダ | 内容 |
|---|---|
| `docs/` | GitHub Pages の公開ルート。`index.html` がアプリ一覧 |
| `docs/apps/` | 教材アプリ（1アプリ1HTMLファイル、外部ライブラリなしで動作） |
| `handouts/` | 授業で配布済みの資料 |

アプリの改良の経緯はコミット履歴と Issues で追えるようにしています。
